- 样式标准
  一、配色标准
  主色原则：以「低饱和度、高辨识度、传递可靠感」为核心，优先选择蓝系（如 #1E88E5、#2196F3 相关低饱和色）或灰蓝系，避免高饱和艳丽色；主色仅用于核心按钮、关键交互元素、品牌标识，不大面积铺陈。
  辅助色规范：
  功能区分：成功状态（低饱和绿系）、警告状态（低饱和黄系）、错误状态（低饱和红系）、信息提示（浅蓝系），辅助色与主色需协调，饱和度统一低于主色，避免视觉冲突。
  使用场景：仅用于提示文案、状态标识、交互反馈（如按钮 hover、输入框 focus），不用于非功能性装饰。
  中性色层级（核心为可读性）：
  背景色：浅灰系（如 #F5F7FA、#FFFFFF），避免过深或刺眼颜色；
  边框色：中浅灰系（如 #E0E6ED），宽度统一 1px，不使用重色边框；
  正文色：深灰系（如 #333647、#4E5969），避免纯黑（#000000）；
  次要文字色：中灰系（如 #6B778C）；
  提示文字色：浅灰系（如 #9AA3B2）；
  对比度要求：正文色与背景色对比度≥4.5:1（符合 WCAG 可读性标准）。
  二、圆角标准
  核心原则：简洁利落，避免过度圆润，突出工具类功能性，同类型元素圆角统一；
  基础元素（按钮、输入框、标签）：2-4px 圆角，优先 3px（平衡柔和与利落）；
  容器类（卡片、面板、列表项）：4-6px 圆角，仅突出层级的核心卡片可使用 6px，普通容器统一 4px；
  弹窗 / 模态框：4-6px 圆角，比普通容器稍大但不超过 8px；
  特殊说明：导航栏、顶部容器等横向通栏元素，可仅设置左右圆角（同基础圆角规格）或保持直角，避免全圆角。
  三、补充样式标准
  边框：统一使用 1px 实线，颜色为中性色中的边框色，仅交互状态（如输入框 focus）可改为主色边框，不使用虚线、双线等复杂边框；
  阴影：仅用于层级区分，不做装饰性阴影：
  卡片 / 面板：低透明度（8-15%）、低模糊半径（2-4px）、无偏移或轻微垂直偏移（0-2px）的浅灰阴影；
  弹窗 / 下拉框：稍强于卡片阴影（透明度 10-18%、模糊半径 4-6px、垂直偏移 2-3px），避免水平偏移；
  禁止使用多重阴影、彩色阴影。
  交互状态色：
  按钮 hover：主色加深 5-10%（保持同色系），无额外边框 / 阴影变化；
  按钮 active：主色加深 10-15%，或添加轻微内阴影（增强按压感）；
  输入框 focus：主色边框 + 低透明度（20-30%）主色外发光（模糊半径 2-3px）；
  可点击元素（如链接、图标）：hover 时颜色加深 5-10%，无下划线（除非是纯文字链接，下划线颜色与文字同色且 hover 时加深）。
  文字样式：
  字体：优先无衬线字体（如 Inter、思源黑体、Roboto），确保跨设备可读性；
  字号层级：正文 14-16px（优先 14px）、标题 16-20px（比正文大 2-4px）、次要文字 12-13px；
  行高：正文 1.5-1.6、标题 1.3-1.4、次要文字 1.4，避免行高过大或过小影响阅读。
  四、核心原则
  一致性：同类型元素（如所有按钮、所有输入框）的配色、圆角、文字样式完全统一；
  功能性：样式服务于使用场景，不添加无意义装饰（如复杂纹理、渐变、多余阴影）；
  可读性：文字、交互元素的颜色、大小、间距以「快速识别、长时间阅读不疲劳」为核心；
  低干扰：颜色、圆角、阴影等样式不抢占功能焦点，突出工具的核心操作逻辑。

在上述基础上,颜色采用浅蓝色色系
